# 关键词漫游器

给一个词,机器吐出它的**上级分类、下级分类、相邻词**(各配一句"为什么值得搜"的说明),
你挑有意思的点了去 B 站搜视频看——半娱乐半学习的关键词兔子洞。

## 启动

```powershell
# 首次:确认环境变量里有 DeepSeek 的 key(本机已设置)
# $env:DEEPSEEK_API_KEY = "sk-..."   # 没有的话,当前窗口临时设一个

python app.py
# 浏览器打开 http://127.0.0.1:8765
```

## 怎么玩

1. 顶部输入任意词(比如 `OpenClaw`、`明朝海禁`、`咖啡豆`),回车;
2. 三个栏位展开:点任何**词**就以它为中心继续漫游,点 **B站/百科/公众号** 跳去搜索;
3. 觉得某个词值得认真挖,点它旁边的 **🔍深挖**:AI 先判断词的类型(事件/人物/概念/地点/组织…),
   再按类型生成 4~6 个专属维度——事件给时间线/关键人物/后果,概念给起源/误解/争议,依此类推;
4. 绿色词 = 漫游过(读缓存,不花钱);底部"足迹"是走过整条路,重启不丢;
5. "口味偏好"栏可以改,比如"越离谱越好"或"只看历史向"——AI 会照办。

## 成本

单次查询约 0.5~1 分钱(输入 ~1k token、输出 ~800 token)。查过的词全部缓存,
不再请求,所以玩得越久、新词越少、账单增速越慢。缓存存在 `data/cache.json`,
删掉它 = 地图清零(慎删,那是你的足迹)。

## 文件

| 文件 | 干什么 |
|---|---|
| `app.py` | Flask 后端:两个 API(`/api/expand` 漫游、`/api/cache` 足迹统计)+ 缓存 |
| `templates/index.html` | 前端页面(原生 JS,无框架) |
| `data/cache.json` | 关键词图缓存(运行后生成) |

## 可调参数(环境变量)

| 变量 | 默认 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | (必填) | DeepSeek 平台申请 |
| `DEEPSEEK_MODEL` | `deepseek-flash` | 另有 `deepseek-v4-pro`(更聪明更贵);可用模型以 `curl api.deepseek.com/models` 实测为准 |

## 已知边界

- 提示词里要求"至少 2 个跨界词",但"有意思浓度"依赖模型发挥,口味不对就多试几次口味栏;
- 偶尔模型返回的 JSON 不合法,后端会报"模型返回解析失败",重试一次通常就好;
- 缓存是单文件 JSON,单人用没问题;想多人/多设备用再升级 SQLite。
